Scrap Product
=============

This application introduces functionality for scrapping products directly from the Product Variants form view via the "On Hand Quantity" smart button. It also allows users to specify a scrap location on scrap orders.

Features
--------

- Scrap Functionality from Product Variants: Allows users to scrap products directly from the Product Variants form view via the "On Hand Quantity" smart button.
- Scrap Location: Users can specify the location where the scrap will occur.
- Scrap Order Management: After confirming a scrap order, the "On Hand" quantity for the product will be updated, reflecting the scrapped units.
- View Scrap Orders: Users can see all scrap orders in a dedicated Scrap Orders view.

How to Use
----------

1) Product Variant Form View:  
   Navigate to Inventory → Products → Product Variant. Here, you will see a smart button for "On Hand," which provides functionality to view and modify the on-hand quantity. After installing the module, it will also allow scrapping products.

2) Product Scrap Pop-up View:  
   In the "On Hand" section of the Product Variant form, you will see new fields for Scrap and Scrap Location. Users can enter the quantity to scrap and specify the scrap location.

3) Product Variants View:  
   After confirming the scrap order, the On Hand quantity for the product will be updated to reflect the scrapped units.

4) Scrap Orders View:  
   Navigate to Inventory → Operations → Scrap to view all scrap orders.

5) Scrap Order Form View:  
   Users can access detailed views of each scrap order.
